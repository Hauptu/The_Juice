# Krafthandel Dashboard 2x2

Public-ready version of the 2x2 dashboard.

## Deployment
1. Put these files in the `krafthandel-dashboard` GitHub repository.
2. Connect the repository to Cloudflare Pages.
3. Add a Cloudflare Pages secret named `ENTSOE_API_KEY`.
4. Deploy.

The ENTSO-E key is intentionally not stored in the frontend.
